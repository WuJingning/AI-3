# AI 消保材料智能审查工具（合同类）

面向消保审查人员的 AI 合规审查网页：上传或粘贴送审合同材料后，由本地服务端调用已配置的扣子（Coze）工作流完成自动审查，页面展示风险等级、原文高亮、问题分析、法条依据与整改建议，并可导出审查意见书。

## 一、页面包含的功能

- **顶栏状态**：显示产品名称与“扣子工作流已连接”状态（以及已脱敏的工作流 ID）。
- **首屏说明**：AI 消保材料智能审查（合同类）、四个审查步骤（提取合同内容 / 查询企业信息 / 审查合同条款 / 生成审查报告）。
- **合同提交**：合同类型、审查立场（甲方 / 乙方 / 中立）、重点审查内容（多选）、补充审查要求、文件上传（点击或拖拽，支持 PDF / Word / TXT / MD，单个不超过 10MB）、粘贴合同文本、开始智能审查、重置。
- **表单校验**：既没有上传文件也没有粘贴文本时给出明确提示；格式或体积不符合要求时即时提示。
- **审查过程**：四个步骤依次变为“进行中 / 已完成”，显示“正在提取文本并逐项分析合同条款，请稍候”等提示，审查期间提交按钮不可重复点击。
- **结果展示**：结论条（高 / 中 / 低风险数量）、审查意见卡片（风险等级标签、问题标题、原文摘录、问题分析、法条依据、整改建议、复制修改建议）、法律引用核验摘要、企业信息核验摘要、飞书完整审查报告入口。
- **双栏工作区**：左侧合同原文按风险等级高亮，右侧风险清单；点击任一意见可定位原文，点击原文高亮可回到对应意见；支持按全部 / 高 / 中 / 低风险筛选。
- **导出与复制**：复制单条修改建议、一键复制全部意见、复制审查意见书（Markdown 全文）、导出 PDF（调用浏览器打印）。
- **历史记录**：浏览器本地保存最近 8 次记录（合同名称、审查时间、意见数量、高风险数量、数据来源），支持清空记录。
- **容错与演示**：扣子工作流未配置或调用失败时给出明确错误提示，可重新尝试，也可一键使用本地模拟结果——所有模拟结果都会标注“当前为演示结果”。

## 二、运行方式

需要本机已安装 Node.js 18 或以上版本（无需安装任何第三方依赖）。

```bash
cd contract-review-workbench
node server.js
```

Windows 下也可以直接双击 `start.cmd`（会在浏览器中打开 <http://localhost:8787>）。

如需让其他人访问（局域网共享、临时公网链接、云服务器 + 域名 HTTPS、托管平台），见 [DEPLOY.md](./DEPLOY.md)。服务提供 `GET /healthz` 健康检查接口，可用 `HOST` 环境变量控制监听地址（`0.0.0.0` 对外开放，`127.0.0.1` 仅本机）。

通过 GitHub 部署（推荐）：仓库已内置 CI（语法检查 + 密钥扫描 + 启动冒烟测试）、镜像发布工作流，以及 Render / Fly.io / Railway 的部署配置，操作步骤见 [DEPLOY.md 的 G 节](./DEPLOY.md#g-通过-github-部署推荐路线)。请注意 **GitHub Pages 不适用**：页面必须由服务端持有访问密钥调用工作流。

## 三、服务端配置

配置支持两种方式，**系统环境变量优先，其次读取项目根目录的 `.env`**：

| 配置项 | 说明 |
| --- | --- |
| `COZE_API_TOKEN` | 扣子个人访问密钥，仅服务端使用 |
| `COZE_WORKFLOW_ID` | 扣子工作流 ID |
| `COZE_API_BASE` | 扣子接口地址，国内站为 `https://api.coze.cn` |
| `PORT` | 本地网页端口，默认 `8787` |
| `ALLOW_TEMP_LINK` | 文件直传不可用时，是否允许通过一次性临时链接把合同内容提交给工作流，默认 `true` |
| `COZE_TIMEOUT_MS` | 单次工作流调用超时时间，默认 `180000` |
| `CONTRACT_REVIEW_DUMP_DIR` | 可选调试项：设置后会把每次工作流原始返回写入该目录，便于核对输出结构；不设置则不落盘 |

`.env` 已被 `.gitignore` 忽略，不会进入代码仓库；页面、浏览器代码与接口响应中都不包含访问密钥。可参考 `.env.example` 了解全部配置项（其中不含任何真实密钥）。

Windows 下如果希望改用**用户级环境变量**（而不是 `.env` 文件），可以运行项目里的辅助脚本，它会自己从 `.env` 读取配置再写入环境变量，无需手动粘贴密钥：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\set-env.ps1
# 或双击 scripts\set-env.cmd
```

脚本为纯 ASCII 内容并按 UTF-8 读取 `.env`，因此在 Windows PowerShell 5.1（系统 ANSI 代码页）与 PowerShell 7 下都能正常运行。

写入后需**关闭并重新打开终端**（或重新登录）才会生效；服务端的读取顺序是「系统环境变量 > 项目 `.env`」。撤销方式：

```powershell
Remove-ItemProperty -Path 'HKCU:\Environment' -Name COZE_API_TOKEN,COZE_WORKFLOW_ID
```

## 四、扣子侧需要确认的信息

1. **工作流 ID**：与 `.env` 中的 `COZE_WORKFLOW_ID` 保持一致。
2. **个人访问令牌**：需要具备执行工作流的权限；如需把用户上传的文件直接提交给工作流（不经过临时链接），还需在令牌中勾选**文件上传**权限。
3. **工作流入参**：本页按以下两个入参调用工作流。
   - `wenjian`：合同文件。优先使用“文件上传”接口返回的 `file_id`，不可用时改用一次性临时链接地址（工作流已验证可直接读取 URL）。
   - `xuqiu`：审查要求文本，内容包含合同类型、审查立场、重点审查内容、补充审查要求以及期望的输出结构。
4. **飞书云文档插件授权**：工作流最后的“合同审查结果上传”节点使用飞书云文档插件。通过 API 调用时若未完成授权，工作流会暂停并返回授权链接，页面会显示“需要完成授权”的提示、授权入口与重试按钮；完成授权后重新提交即可返回完整结果。
5. **输出结构**：工作流返回的字段命名与排版在不同运行之间可能变化，页面会自动兼容常见写法（Markdown 列表、`### 章节`、`1）章节：`、行内“字段：值”等），并识别 `审查意见`、`风险等级`、`问题分析`、`修改建议`、`法条依据` 等中英文字段别名；无法结构化识别时会原样展示“工作流原始输出”。
6. **字段缺失时的表现**：若某次返回没有给出“风险等级”，页面按“未分级”展示并单独统计，不会擅自归入中风险；若没有给出“原文摘录”，页面会在本地按关键词重合度从合同原文中匹配对应条款，并明确标注为“本地匹配”，仅用于阅读定位。建议在工作流输出中固定保留这两个字段，以获得更准确的展示。

## 五、演示完整流程

1. 启动服务：`node server.js`，打开 <http://localhost:8787>。
2. 选择合同类型与审查立场，勾选重点审查内容，可填写补充审查要求。
3. 上传合同文件，或直接粘贴合同文本（两者至少填一项，否则会提示）。
4. 点击“开始智能审查”：四个步骤依次推进，页面调用服务端接口并等待扣子工作流返回。
5. 查看结果：结论条中的高 / 中 / 低风险数量、左右双栏的原文高亮与风险清单、法律引用核验与企业信息核验摘要。
6. 在风险清单中点击任意一条意见可定位原文；用筛选按钮只看某一风险等级；用“复制修改建议”“一键复制全部意见”“复制审查意见书”“导出 PDF”输出结果。
7. 如果工作流未连接或调用失败：页面显示错误原因，可点击“重新尝试”，也可以点击“使用演示结果”查看完整交互（会明确标注“当前为演示结果”）。
8. 审查完成后，历史记录区域会保存本次记录，可随时清空。

## 六、目录结构

```
contract-review-workbench/
├─ server.js            # 本地服务：静态页面 + 服务端调用扣子工作流
├─ lib/
│  ├─ config.js         # 配置读取与密钥脱敏
│  ├─ coze.js           # 扣子接口封装（文件上传、工作流执行、临时链接）
│  ├─ normalize.js      # 工作流返回结果结构化
│  ├─ extract.js        # TXT / MD / DOCX 文本提取
│  └─ demo.js           # 本地演示数据（不足时兜底展示）
├─ public/
│  ├─ index.html        # 页面结构
│  ├─ styles.css        # 政务蓝风格样式与响应式布局
│  └─ app.js            # 交互逻辑（提交、进度、结果、筛选、复制、历史）
├─ .env                 # 本机密钥配置（已被 gitignore，请勿提交）
├─ .env.example         # 配置模板（不含真实密钥）
├─ start.cmd            # Windows 一键启动
└─ package.json
```

## 七、常见提示与处理

| 页面提示 | 处理方式 |
| --- | --- |
| 请先上传合同文件或粘贴合同文本 | 上传文件或粘贴文本后重新提交 |
| 当前访问密钥没有“文件上传”权限 | 在扣子个人访问令牌中勾选文件上传权限，或在提交区域保留“一次性临时链接提交” |
| 扣子工作流需要完成授权 | 点击提示中的“打开飞书授权页面”完成授权，再点击“重新尝试” |
| 未检测到扣子工作流配置 | 填写 `.env` 中的 `COZE_WORKFLOW_ID` 与 `COZE_API_TOKEN` 后重启服务 |
| 当前为演示结果 | 说明本次未获取到工作流真实返回，页面使用本地示例数据 |
